## 🐞 오늘 만난 에러: `422 Invalid control character`

```json
{
  "type": "json_invalid",
  "msg": "JSON decode error",
  "ctx": { "error": "Invalid control character at" }
}
```

- **뜻:** JSON 문자열 값(`"..."`) 안에 **진짜 줄바꿈(엔터)이나 탭** 같은 보이지 않는 특수문자가 끼어들었다는 것.
- **왜 안 되나:** JSON 규칙상 `"..."` 따옴표 안에는 진짜 줄바꿈이 들어갈 수 없음. 줄바꿈을 값으로 넣고 싶으면 `\n`처럼 써야 함.
- **원인:** Swagger 입력창에 여러 줄 JSON을 붙여넣을 때 값 중간에 줄바꿈이 하나 섞여 들어감.
- **해결:** JSON을 **한 줄로 압축(minify)** 해서 붙여넣음 → 줄바꿈이 아예 없으니 문제 사라짐.
- **배운 것:** `loc: ["body", 99]`의 숫자 99 = **에러가 난 글자 위치(몇 번째 문자)**. 어디가 문제인지 위치를 알려주는 힌트.
