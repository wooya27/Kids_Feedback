# 📝 문제 파트

## 문제 1 — 하나씩 꺼내서 찍기

리스트에 있는 아이 이름을 **한 줄에 하나씩** 화면에 찍어라.

```python
아이들 = ["유리", "민수", "지호"]

# 여기에 for문 작성
```

**원하는 결과**
```
유리
민수
지호
```

💡 힌트: `for 이름 in 리스트:` 형태. 꺼낸 걸 담을 이름표는 네가 짓는 거야.

---

## 문제 2 — 빈 통에 담기 (append)

숫자 리스트의 각 숫자에 **2를 곱해서**, 새 리스트 `결과`에 담고 마지막에 찍어라.

```python
숫자들 = [1, 2, 3, 4]
결과 = []

# 여기에 for문 작성

print(결과)
```

**원하는 결과**
```
[2, 4, 6, 8]
```

💡 힌트: 빈 통 `결과`는 이미 만들어놨어. `.append()`로 하나씩 넣어.
⚠️ 주의: `print(결과)`는 반복 **밖**이야. 들여쓰기 확인!

---

## 문제 3 — strip 붙이기

각 문장의 **앞뒤 공백과 줄바꿈을 지워서** 새 리스트에 담아라.

```python
문장들 = ["  안녕\n", "\n  반가워  ", "  잘가  \n"]
깨끗한것 = []

# 여기에 for문 작성

print(깨끗한것)
```

**원하는 결과**
```
['안녕', '반가워', '잘가']
```

💡 힌트: 꺼낸 문장에 `.strip()`을 붙인 결과를 `append`한다. 문제 2와 뼈대가 똑같아.

---

## 문제 4 — 슬라이싱 + for (실전 그대로)

리스트의 **0번은 버리고, 1번부터** 앞뒤 공백을 지워서 담아라.
(← Day 9 chunking에서 실제로 하는 일이 이거다)

```python
조각들 = ["문서 머리말입니다", "  질문: 첫번째\n", "  질문: 두번째\n"]
chunks = []

# 여기에 for문 작성

print(chunks)
```

**원하는 결과**
```
['질문: 첫번째', '질문: 두번째']
```

💡 힌트: `for c in 조각들[1:]:` — 슬라이싱을 `for` 뒤에 바로 붙여 쓸 수 있어.

---

## 문제 5 — 도전: 골라 담기 (if)

빈 조각(내용 없는 것)은 **빼고** 담아라.

```python
조각들 = ["질문: 첫번째", "", "질문: 두번째", "   ", "질문: 세번째"]
chunks = []

# 여기에 for문 작성

print(chunks)
```

**원하는 결과**
```
['질문: 첫번째', '질문: 두번째', '질문: 세번째']
```

💡 힌트: `if`라는 새 문법이 필요해. "조건이 맞을 때만 담아라"라는 뜻이야.
- `if 조건:` 아래 들여쓴 줄은 **조건이 맞을 때만** 실행돼
- 파이썬에서 **빈 문자열 `""`은 "거짓"** 취급이야. 내용이 있으면 "참".
- `"   "`(공백만 있는 것)은 strip하면 `""`이 된다는 걸 이용해봐.

⚠️ 이 문제는 못 풀어도 정상. 답 보고 이해만 해도 충분해.

# ✅ 답 파트 (문제 다 풀고 나서 보기)

---

## 답 1

```python
아이들 = ["유리", "민수", "지호"]

for 이름 in 아이들:
    print(이름)
```

**왜 이렇게 되나**
- `for 이름 in 아이들:` → 리스트에서 하나씩 꺼내서 `이름`에 담아라. 3개니까 3바퀴 돈다.
- `이름`은 내가 지은 이름표일 뿐. `x`든 `child`든 아무거나 돼.
- 끝의 `:` 빼먹으면 `SyntaxError`. **for문 끝엔 항상 콜론.**
- `print(이름)`은 들여쓰기 되어 있음 → 매 바퀴마다 실행 → 3번 찍힘. 여기선 이게 맞아.

---

## 답 2

```python
숫자들 = [1, 2, 3, 4]
결과 = []

for n in 숫자들:
    결과.append(n * 2)

print(결과)
```

**왜 이렇게 되나**
- `결과 = []` → 빈 통. 담을 그릇을 **먼저** 만들어야 해. 없으면 넣을 데가 없어 에러.
- `n * 2` → 꺼낸 숫자에 2를 곱한 **결과값**
- `.append(...)` → 그 값을 통에 **넣는다**
- `print(결과)`는 들여쓰기 **없음** → 반복이 다 끝난 뒤 한 번만 실행

**흔한 실수**: `print`를 들여쓰면 4번 찍힌다.
```
[2]
[2, 4]
[2, 4, 6]
[2, 4, 6, 8]
```
통에 하나씩 쌓이는 과정이 다 보이지. 이건 **틀린 건 아니고** 중간과정을 보고 싶을 땐 일부러 이렇게도 해.

---

## 답 3

```python
문장들 = ["  안녕\n", "\n  반가워  ", "  잘가  \n"]
깨끗한것 = []

for 문장 in 문장들:
    깨끗한것.append(문장.strip())

print(깨끗한것)
```

**왜 이렇게 되나**
- 문제 2와 **뼈대가 완전히 같다.** 바뀐 건 `n * 2` → `문장.strip()` 하나뿐.
  → 이 뼈대(빈 통 → for → append → print)가 앞으로 계속 나오는 기본형이야.
- `.strip()`은 **앞뒤만** 지워. 가운데 공백은 안 건드림.
- `\n`은 줄바꿈 한 글자야. `.strip()`이 공백과 함께 같이 지워준다.

**안에서 바깥으로 읽는 법**: `깨끗한것.append(문장.strip())`
1. `문장.strip()` 먼저 실행 → 깨끗해진 문자열이 나옴
2. 그걸 `append`가 받아서 통에 넣음

---

## 답 4

```python
조각들 = ["문서 머리말입니다", "  질문: 첫번째\n", "  질문: 두번째\n"]
chunks = []

for c in 조각들[1:]:
    chunks.append(c.strip())

print(chunks)
```

**왜 이렇게 되나**
- `조각들[1:]` → **1번부터 끝까지.** 0번("문서 머리말입니다")은 아예 반복에 들어오지 않아.
  - 파이썬은 **0번부터 센다**. 0번을 버리려면 `[1:]`
  - 끝 숫자를 안 쓰면 "끝까지"라는 뜻
- 슬라이싱을 `for` 뒤에 **바로 붙여 쓸 수 있다**. 미리 변수에 담을 필요 없어.
- 나머지는 답 3과 동일.

**이게 `kids.py`에서 하는 일 그대로다.** 이 문제가 풀리면 실전도 풀린 거야.

---

## 답 5

```python
조각들 = ["질문: 첫번째", "", "질문: 두번째", "   ", "질문: 세번째"]
chunks = []

for c in 조각들:
    깨끗 = c.strip()
    if 깨끗:
        chunks.append(깨끗)

print(chunks)
```

**왜 이렇게 되나**

`if 조건:` = **조건이 맞을 때만** 아래 들여쓴 줄을 실행해라.

- `깨끗 = c.strip()` → 먼저 공백을 턴 결과를 `깨끗`이라는 이름에 담아둔다
  - 왜 변수에 담나? `strip()`한 결과를 **두 번 쓰기 때문**(조건 검사 1번, append 1번).
    변수에 담아두면 같은 계산을 두 번 안 해도 되고 읽기도 쉬워.
  - `"   "`(공백만)은 strip하면 `""`(빈 문자열)이 된다 ← 이게 이 문제의 핵심
- `if 깨끗:` → "`깨끗`에 내용이 있으면"
  - 파이썬은 **빈 문자열 `""`을 거짓**으로 본다. 내용이 있으면 참.
  - 그래서 `if 깨끗:`만 써도 "비어있지 않으면"이라는 뜻이 돼. `if 깨끗 != "":` 라고 길게 써도 같은 뜻.
- 들여쓰기가 **2단**인 것에 주목:
  ```
  for ...:              ← 1단: 반복
      깨끗 = ...         ← 2단: 매 바퀴 실행
      if 깨끗:           ← 2단: 매 바퀴 검사
          chunks.append  ← 3단: 조건 맞을 때만 실행
  ```
  들여쓰기 단계 = **누구 소속인지**를 나타내는 문법이야. 눈으로 보기 좋으라고 하는 게 아님.

# 🎯 이 연습에서 가져갈 것 (한 줄 정리)

> **빈 통 만들기 → `for`로 하나씩 꺼내기 → 가공해서 `append` → 반복 밖에서 `print`**

이 4단 뼈대가 파이썬에서 제일 많이 쓰는 형태야.
문제 2~5는 전부 이 뼈대에 **가공 방법만 바꾼 것**이다.

## 자주 만나는 에러

| 에러 메시지 | 원인 |
|---|---|
| `SyntaxError` (for 줄) | 끝에 `:` 빼먹음 |
| `IndentationError` | 들여쓰기가 안 맞음 (스페이스 4칸으로 통일) |
| `NameError: '결과' is not defined` | 빈 통을 미리 안 만들었음 |
| `AttributeError: 'list' object has no attribute 'strip'` | 리스트에 `.strip()` 씀 — strip은 **문자열 하나**에만 |
| 결과가 여러 번 찍힘 | `print`가 반복 **안**에 들여써져 있음 |
