## 1. 오늘 잡은 핵심 개념 (한 줄 요약)

1. **조각(chunk) = 질문 1개당 대답 1개.**
2. **질문 ↔ 대답이 어긋나면 검색 실패하거나 딴소리한다.**
3. **골격 3덩어리:** `[누구가/언제] → [뭘 한다 + 실제 할 말] → [왜 그 유형한테 효과적]`
4. **RAG 안에 chunk → embedding → 검색 → 답생성**이 순서대로 들어있다.
5. **RAG 자료 = "AI가 이미 아는 뻔한 일반론"이 아니라 "우리만 아는 노하우"다.**

## 2. 오늘 내가 물어봤던 질문 & 답 (복습용)

### Q1. "chunk 하는데 질문과 대답이 어긋나면 어떻게 돼?"
- RAG는 조각을 순서대로 안 읽고 **"질문과 닮은 조각"을 찾아서** 꺼내온다.
- 어긋나면 두 가지 사고:
  - **못 찾아온다(검색 실패):** 질문엔 "말"이 있는데 조각엔 "행동"만 있으면 안 닮아서 안 꺼내옴 → 애써 쓴 조각이 잠잠.
  - **찾아와도 딴소리:** 질문은 "할 말"을 원했는데 조각은 "안아줘라"면 동문서답 → AI가 자신 있게 틀린 답.
- ✅ 한 줄: **조각 = "그 질문이 들어왔을 때 꺼내와서 그대로 답이 되는 것."**

### Q2. "rag, chunk, embedding 이게 다 같이 가나? / RAG 안에 chunk랑 embedding이 있는 거야?"
- **맞다. RAG는 큰 통(전체 시스템), chunk·embedding은 그 안의 단계(부품).**
- 파이프라인:
  ```
  [문서] → ①chunk → ②embedding → ③저장 → ④검색 → ⑤답 생성
          (조각내기) (숫자로 변환) (창고에) (닮은거 꺼냄) (AI가 답)
  ```
- **순서 중요:** chunk가 먼저, embedding이 그다음. chunk가 잘못되면 embedding·검색도 다 어긋남.
- 비유: RAG = 도서관에서 책 찾아 답해주는 시스템 / chunk = 찾기 좋게 조각내기 / embedding = 찾기 쉬운 색인표(숫자) 붙이기.

### Q3. "RAG는 보통 완성된 자료(아이심리학 책 등)를 가져오는 거 아냐? 내가 하는 건 뭐야?"
- RAG 자료는 **남의 책이든 내가 쓴 거든 상관없다. 정하는 사람 맘.**
- 내가 직접 쓰는 이유 2가지:
  1. AI는 일반 심리학(뻔한 일반론)은 이미 안다 → 넣을 가치 X.
  2. 진짜 가치는 **"이 학원만의 방식"** (위축형은 결과 말고 시도를 칭찬 등) → 어느 책에도 없음 → AI가 모름 → 내가 써서 넣어야 함.
- ✅ 내가 하는 일 = **"AI가 모르는, 우리 학원만의 노하우를 조각으로 정리하는 것."**

### Q4. "조각 하나(질문1+답1)로 RAG가 돼? 내용이 더 있어야 하는 거 아냐?"
- 내용은 더 있어야 맞다. 단, **"한 조각을 길게"가 아니라 "조각을 많이".**
- 함정: 한 조각에 이것저것 욱여넣으면 ①요약 테스트가 깨져서 검색이 헷갈린다.
- ✅ **조각 하나는 작고 뾰족하게, 대신 그런 조각을 많이.** 양은 개수에서 나온다.

### Q5. "한 파일 안에 조각 여러 개를 다 넣어?"
- **응. 주제별 파일 하나 안에 관련 조각들을 모은다.** (`##` 제목으로 경계선)
- 두 기준이 다르다:
  - **파일 나누는 기준** = 사람이 관리하기 편한 단위(주제별).
  - **조각 나누는 기준** = ①②③ 테스트(질문1=대답1). 검색 잘 되라고.

### Q6. "여러 유형 아이가 있는데?" (위축형/승부욕형/평범형)
- 그래서 **파일을 유형별로 여러 개** 만든다. 유형이 많아도 **틀(골격)은 하나**라 내용만 갈아끼우면 됨.

## 3. 조각(chunk) 만드는 규칙 — 3가지 테스트

| 테스트 | 뜻 | 예 |
|---|---|---|
| **①요약** | 이 조각은 ___를 말한다 → **하나만** | 한 조각에 칭찬법+훈육법 섞으면 X |
| **②독립** | 조각만 **떼어 읽어도 말 됨** (대명사·생략 금지) | "걔가 그걸 했을 때"(X) → "위축형 아이가 발표를 해냈을 때"(O) |
| **③골격** | `[누구/언제] → [뭘 한다+실제 말] → [왜 효과적]` | 아래 견본 참고 |

### 골격 견본 (평범형 성장법)
```
## 질문: 평범형 아이를 어떻게 성장시키나요?

평범형 아이는 "지난번보다 나아진 점"을 콕 집어 짚으며 다음 목표를 하나 준다.   ← [누구+뭘 한다]
"저번엔 여기서 멈췄는데 오늘은 끝까지 했네, 다음엔 속도도 붙여보자"라고 말한다.  ← [실제 할 말 예시]
평범형은 관심에서 밀리기 쉬운데, 남이 아니라 자기 과거와 비교해주면
소외감 없이 꾸준히 성장하려는 동기가 생긴다.                                  ← [왜 효과적]
```
