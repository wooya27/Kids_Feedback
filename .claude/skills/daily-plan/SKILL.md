# 오늘 할 일 뽑기 (daily-plan)

전체 지도(`Kids_Feedback_DAY3플랜.md`)에서 **지금 어디까지 했는지** 확인하고,
**다음 한 세션 분량만** 오늘치로 뽑아 `todayplan.md`에 적어준다.
목적은 "전체를 보고 압도되지 않고, 지금 닫을 작업 1개만 명확히" 하는 것.
ADHD 작업 규칙(`.claude/sjy_st.md`)에 맞춰 한 번에 세션 1개만 준다.

## 파일 역할
- **원본 지도:** `Kids_Feedback/plan/Kids_Feedback_DAY3플랜.md` — DAY 1~3 전체 로드맵(각 Day 작업 체크리스트). "무엇을 만들지"의 출처.
- **일일 작업지:** 프로젝트 루트 `todayplan.md` — 오늘 할 만큼만 뽑아온 목록.
- (참고용 구버전 `Kids_Feedback/plan/plan.md`는 기준 아님.)

## 순서 (이대로)
1. **현재 진도 파악:** `todayplan.md`의 완료 상태 + `git log --oneline -10` 으로 지금 어디까지 했는지 먼저 확인한다. 추측하지 않는다.
2. **다음 단계 찾기:** `Kids_Feedback_DAY3플랜.md`에서 방금 진도 **다음에 올 단계/체크박스**를 찾는다.
3. **한 세션만 뽑기:** 그중 **25~40분 안에 닫을 수 있는 1개 작업단위**만 고른다. 전체를 쏟아붓지 않는다.
4. **todayplan.md에 적기:** 아래 형식으로 새 세션을 `todayplan.md` 맨 위(다음 할 일 자리)에 추가한다.

## todayplan.md 세션 형식 (sjy_st 기준)
```
## 세션 (30분) — [무슨 작업]
> 지금은 확장 금지 — 이 작업 하나만 닫는다.
- [ ] (할 일 1)
- [ ] (할 일 2)
- 끝나면 보여야 할 결과:
```

## 주의
- 일을 키우려 하면 "지금은 확장 금지, 이번 결과만 닫기"라고 말해준다.
- `Kids_Feedback_DAY3플랜.md`는 원본 지도이므로 함부로 바꾸지 않는다. 계획 자체가 바뀔 때만 사용자 확인 후 수정한다.
- 작업 완료 때마다 `todayplan.md`를 `- [x]`로 체크하고 "완료" 섹션으로 옮기는 것은 이 스킬과 별개로 항상 한다.
