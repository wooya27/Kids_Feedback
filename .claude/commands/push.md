---
description: 현재 변경사항을 커밋하고 원격(origin)에 푸시한다
---

사용자가 `/push`를 실행했다. 아래 순서대로 변경사항을 커밋하고 푸시해라.

1. `git status`와 `git diff --stat`으로 현재 변경사항을 확인한다.
2. 변경된 파일 전체를 스테이징한다 (`git add -A`).
3. 변경 내용을 보고 **한글 커밋 메시지**를 직접 만든다.
   - 첫 줄: 무엇을 왜 바꿨는지 50자 내외 요약.
   - 여러 종류의 작업이 섞여 있으면 본문에 `- ` 불릿으로 나눠 적는다.
   - 커밋 메시지 끝에 다음 줄을 반드시 붙인다:
     `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`
4. 현재 브랜치 이름을 확인하고 `git push origin <현재브랜치>`로 푸시한다.
5. 끝나면 푸시된 커밋 해시 범위(예: `6d7195b..adf752c`)와 브랜치를 한 줄로 보고한다.

주의:
- 커밋/푸시는 되돌리기 번거로우니, 서로 성격이 완전히 다른 작업이 많이 섞여 있으면
  한 커밋으로 묶기 전에 "따로 나눌까?"라고 한 번 물어본다.
- 푸시 전 실패(충돌 등)하면 그대로 멈추고 상황을 설명한다. 함부로 `--force` 하지 않는다.

$ARGUMENTS 가 있으면 그것을 커밋 메시지 첫 줄로 사용한다.
