## 작성·검토 원칙 (P0-3 품질 기준)
- 한 청크(`## 질문: ...`)는 **하나의 질문에 답하는 독립 지침**으로 작성 → Top-k 검색에서 개별적으로 뽑히도록.
- 각 문서는 제목 / 상황 / 권장 언어·행동 / 피해야 할 표현 / 예시 / 출처·검토 여부를 포함.
- 근거 없는 교육 효과·진단성 표현·아동 낙인 서술 배제. 성향은 관찰 가능한 행동으로 기술.
- 출처 미확인 → `source=자체작성가이드(전문가검증전)`로 명시.
- 아동 실명·실제 민감정보는 문서·샘플에 넣지 않음(합성 데이터만).

## MVP 범위 메모
- 체크리스트의 정식 목표는 22~30개. 이번은 **MVP 15개**로 핵심 성향·상황·성장·학부모 범주를 고르게 확보.
- 추가 확장 후보: 소극적/활발한 참여, 차분한 성향, 수업 참여 거부, 규칙 이해 어려움, 새로운 동작 도전, 가정 연계 활동 등.
