# RAG 적용 전/후 피드백 품질 비교 (P1-1)

> 목표: 검색 점수만 높인 게 아니라 **실제 개인화된 피드백이 더 적절해졌는지** 사람이 평가한다.

## 조건
- 같은 활동(양발 모아 뛰기), 성향만 다른 합성 학생 3명(위축형/산만형/완벽주의형).
- 동일 모델(`gemini-2.5-flash`) · 동일 프롬프트 틀.
- 3가지 변형: **A) RAG 미사용 / B) Top-1 / C) Top-3**.
- 생성 스크립트: `evals/compare_rag_variants.py` → 결과 `evals/rag_variant_outputs.json`.

## 실행
```bash
docker compose exec api python -m evals.compare_rag_variants
```

## 평가 기준 (사람이 직접 채점 · 1~5점)
| 기준 | 설명 |
|---|---|
| 학생 특성 반영 | 성향(위축/산만/완벽주의)이 피드백에 드러나는가 |
| 지도 근거 일치 | 검색된 근거와 내용이 맞아떨어지는가 |
| 과장·진단 표현 부재 | '천재/ADHD' 같은 단정·진단 표현이 없는가 |
| 다음 목표 구체성 | next_goal이 실행 가능할 만큼 구체적인가 |
| 학부모 표현 적절성 | parent_feedback이 따뜻하고 내부메모 노출이 없는가 |
